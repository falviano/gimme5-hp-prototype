# Stakeholder Preferences

## COSMICO/PLAYNEW TEAM

### Filippo Alviano (UX/UI Designer, project lead)
- ROLE: Lead designer, wireframes, DS, client communication
- Principle: guide user one step at a time, don't overwhelm with options
- [+] as hub: everything starts from [+], like Instagram
- Wireframe: strictly B&W, no brand colors
- DS: incremental, MD3, dark mode from start
- Salvadanaio: accumulation point, navigate inside for actions (not from card surface)
- Card: super-ellipse corners (squircle), not standard rounded
- UI: flat, no shadows except floating buttons
- Colors: separate palettes for funds (4 institutional colors) and categories (7+ accent colors)
- Preleva: ONLY accessible from [+] menu, never as prominent CTA
- Terminology champion: pushed "routine", "sfida", "trigger", "versa rapido"

### Sarah Corti (PM / UX Strategist)
- ROLE: Project manager, strategic UX, user research, notification strategy
- Approach: HP as dynamic Lego blocks configured per user state
- Educational content: dispersed contextually, behavioral triggers
- FOMO: quantify with real data (days since signup, potential gains)
- User categorization: push to codify user types for personalization
- Community: "spalmata nelle varie sezioni", not a single container
- Notifications: 4 categories (transazionali, patto, motivazionali, educative) with backoff rule
- Terminology: proposed "Gimmi" (not adopted), advocates clear naming
- Unsplash API: proposed for objective images (free up to 50/hr)
- Animation: champions dynamic welcome (references Ponio Bitcoin app for engagement)

### Rinaldo (Developer, Cosmico)
- ROLE: Frontend developer building Flutter prototype
- Attends weekly calls, minimal vocal presence in transcripts
- Builds what Filippo designs -- implementation partner
- Present at all calls from Apr 2 onward

## ACOMEA SGR TEAM

### Giuseppe Codazzi (Product / Strategy)
- ROLE: Product owner, strategic vision, business priorities
- Wants: emotional engagement over financial data, three pillars (obiettivi, automazioni, community)
- Recurring concern: HP too full, too financial, not enough engagement
- Prefers illustrated style over 3D for warmth and resource efficiency
- Pushed "routine" as term replacement for "regola"
- Colors: likes using color for fund risk communication, approves palette extension
- Key priorities (May 6): "obiettivi, routine, community, member-get-member, concorso, AI interazione"
- Warns against over-categorization: "non puoi imporre un'esperienza utente alla base di quello che vuoi analizzare"
- Wants to show Giordano/Alberto something by end of week (pressure for visible progress)
- Salvadanaio approach: liked Filippo's "forzatura" of guiding to first objective (May 13)
- On automatisms: "il tema dell'automatismo dovremmo cercare di trovare piu nudge"
- Academic research partner: co-authored papers with Gargano/Rossi on goal-setting and recurring rules

### Alessandro Marengoni (Frontend Developer + UX Hybrid)
- ROLE: Lead frontend developer with strong UX opinions, technical decision-maker
- Wants: simple CTA (1 action = 1 button), minimal decoration, fattibilita tecnica
- Card obiettivo: compact, scroll orizzontale, more usage screens needed
- Colors: "dettaglio decorativo" not full-colored cards for funds
- Salvadanaio: strong advocate, wants very engaging CTA to convert to objective
- Chatbot space: approved top-right of HP (replaces deprecated notification bell)
- Notifications: moved to Profile tab
- Fund info in card: "un'esplorazione piu avanzata", keep minimal, detail on tap
- Supporters/participants: imagined as avatar row, not full section in card
- Operations: 3 types (versamento non investito, in elaborazione, storico)
- Key pattern: "non mi fanno impazzire le CTA che hanno piu di uno scopo" (May 11)
- Subcategories: wants forced naming (not free text) for data quality, but user can override
- Switch operation: wants versa+preleva+switch as core actions per objective (May 11)
- Prioritization: "a livello di priorita farei l'opposto -- suggerimenti in risalto, input secondario" (May 13)

### Fabio Arlati (Backend Developer, external)
- ROLE: Backend developer, technical feasibility gatekeeper
- Technical realist: flags complexity early
- Pause routine: "non e banalissimo" cross-rules, suggests per-rule approach
- Performance calcs: daily variation easier than 30-day, warns about invested amounts
- Utile: distinguishes "in corso" vs "rimborsato" vs "totale" -- unresolved
- API load: concerned about 4 HP calls, wants async widget loading
- Switch: "c'e un po' di ragionamento dietro, non e immediata"
- MVP advocate: "partiamo dal nucleo che abbiamo"
- Photo quality: warns about ugly user photos on cards

### Marco Vigano (Developer / Business, AcomeA)
- ROLE: Developer with business knowledge, fund expertise, simplicity advocate
- Wants: accurate financial data, transparent communication, app live ASAP
- Concern: CF as first abandonment point, need reassurance
- Routine display: only effective recurrence, not trigger/sfida amounts
- Market alerts: needs sensible algorithm for thresholds (Fabio to develop)
- Progress bar: wants market effect visualized (utile/perdita impacts completion)
- Subcategories: wants them for data quality but respects user freedom
- Community banners: "fattibile e gestibile" -- approves dynamic counters
- Utile display: prefers FIFO approach (first in first out) for calculation
- Key quote: "vorrei vedere quest'app live il prima possibile" -- simplicity advocate
- Obiettivo date: below 1 year makes no sense, suggest 1yr minimum
- Shared objectives: likes, sees business value

### Andres Pardo (Brand / Design, AcomeA)
- ROLE: Brand guardian, visual design oversight, accessibility advocate
- Wants: brand coherence, either colors for objectives OR funds (not both)
- Needs: HP support for multiple priority communications (sometimes 2-3 items)
- Confirms: orange primary scale + neutral gradations as base
- Accessibility champion: warns about photo+text contrast, needs gradient layer
- Color semantics: "occhio per colori che a livello semantico ti dicono qualcosa" (verde=positivo)
- Rule 60/30/10 for color distribution
- Will test scalability of illustration style
- Questions redundancy of Obiettivi tab if HP shows all objectives (May 13)
- Joink accumulation: accumulates monthly, single versament at month end (knows operational detail)
- Communication cards: needs dismiss (X) option for some, forced view for others
- Flat design: "a me non da fastidio" (approved)
